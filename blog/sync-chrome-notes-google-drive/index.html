How to sync Chrome notes with Google Drive

Open Alt+Q Notes in Chrome’s side panel, choose Sync across devices, and approve access to the extension’s own Drive data. Connect the same Google account in each desktop Chrome profile you want to sync.

By the Alt+Q Notes team · November 25, 2026 · Workflow for Alt+Q Notes 0.4.2

Connect both Chrome profiles

  1. Install Alt+Q Notes on both computers or in both desktop Chrome profiles. Open the extension’s side panel on the first one and select Sync across devices.
  2. Choose the Google account you want to use for your notes and approve the Drive prompt. If the panel shows Ready to start sync, select Start sync. Wait for Synced.
  3. Open the extension in the other profile, connect the same Google account, and wait for Synced there as well. The first connection merges saved notes already on that device with the notes stored for that account.

Check which Google account you choose. If you connect a different account later, the notes still on this device can be merged into that account.

Check that a note arrives

On the first device, save a short test note such as “Drive sync test.” Add an image or a saved link if you want to check attachments. Wait for Synced and look for the same note and attachment on the other device. Use Sync now in the side panel to request a check.

If you go offline, keep saving on the current device. The extension keeps those changes locally and retries when it can connect. If the panel asks you to reconnect, confirm you’re using the same Google account. If two edits conflict, Alt+Q Notes keeps both versions for review.

What syncs and what stays on this device

Sync covers saved notes, attached images, saved tab titles and links, and Trash. Unsaved drafts stay in the current Chrome profile. The extension uses a hidden app-data area in your Drive. Your regular Drive files are outside that access scope.

Sync is optional. Choose Log out in the side panel to stop syncing that device. The notes already on the device and the copies in Drive remain. Read how Alt+Q Notes uses Drive.
